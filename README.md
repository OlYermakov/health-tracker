# Health Glass

Особистий 12-тижневий health tracker у темному Liquid Glass стилі.

## Можливості

- 12 тижнів відстеження звичок
- білковий сніданок, овочі, вода та тренування
- стартова й поточна вага
- оцінка самопочуття
- графік динаміки ваги
- відсоток виконання плану
- експорт та імпорт даних у JSON
- локальне збереження через `localStorage`

## Конфіденційність

Особисті значення не записані в код репозиторію. Дані, які вводяться у застосунку, зберігаються локально у браузері на конкретному пристрої.

## Запуск

Відкрий `index.html` у браузері або опублікуй репозиторій через GitHub Pages.
