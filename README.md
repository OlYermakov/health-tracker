# 12-тижневий health tracker

Особистий адаптивний вебзастосунок для 12-тижневої програми зниження ваги та регулярних тренувань. Інтерфейс виконаний у темному Liquid Glass стилі й оптимізований для комп’ютера та телефона.

## Можливості

- 12 тижнів відстеження білкового сніданку, овочів, води й тренувань;
- календар програми з автоматичними діапазонами дат;
- стартова та тижнева вага з графіком і перевіркою введення;
- оцінка самопочуття, сну, енергії, активності та болю в кожному коліні;
- програми тренувань A і B з детальною технікою виконання;
- журнал робочої ваги/опору та повторів для кожної вправи;
- захист від зарахування порожнього тренування і від тренувань A/B в один день;
- нотатки для кожного дня;
- підсумки виконання, тренувань і зміни ваги;
- резервне копіювання та відновлення даних у JSON;
- встановлення на телефон як PWA та робота офлайн;
- локальне збереження без передавання особистих даних на сервер.

## Збереження даних

Дані зберігаються у `localStorage` конкретного браузера. Для захисту від втрати даних періодично натискай **«Зберегти копію»**. Кнопка **«Відновити»** переносить дані з резервного JSON-файлу на поточний пристрій.

Особисті значення не записуються в репозиторій.

## Запуск

Відкрий опубліковану GitHub Pages-сторінку або запусти локальний HTTP-сервер у корені репозиторію. Для офлайн-режиму й встановлення PWA потрібен HTTPS або `localhost`.

> Це не медичний застосунок. За болю, набряку, блокування чи нестабільності коліна припини вправу та звернися до лікаря або фізіотерапевта.
